# Core attr
The game core has a `settings` attribute; it is used to save attributes in JSON format but also serves other purposes—such as music volume, which needs to be stored and utilized within the game.


# World
The game world needs to be built using a tilemap; I plan to use the .tmx format and LibGDX's built-in classes for map creation. It is also important to implement collision logic—converting tiles into functional classes for collisions and other game mechanics.
